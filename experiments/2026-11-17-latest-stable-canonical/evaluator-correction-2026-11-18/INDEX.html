Does setup need an LLM?

No. Imports, build commands, file hashes, data parsing and positive/negative tests produce checkable evidence. An LLM can suggest why a check failed and propose a repair; execution must establish whether that repair works. An LLM's approval is not a readiness certificate. Before restart, explicit source-bound input roles, file formats, metadata and output rules must also be checked in both audience conditions. Upstream library bugs are separate from setup faults.

MDAnalysis now has 160 imported defining modules, 523 upstream data files, 18 input roles, and passing IMD, Chemfiles and real 3DNA checks. These establish audited setup capability, not semantic correctness of every retained API. Final setup report.
