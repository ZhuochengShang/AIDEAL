class MDAnalysis.topology.LAMMPSParser.LammpsDumpParser(filename)[source]

Parses Lammps ascii dump files.

id, mol, type, mass, element and q columns are read and used to set the corresponding topology attributes.

All other columns are ignored.

If masses are not provided they will attempt to be guessed from element names. If no element names are provided then all masses will be set to 1.0.

Added in version 0.19.0.

Changed in version 2.0.0: Allow for a more flexible column layout

Changed in version 2.10.0: Allow reading of mass, charge and element attributes
