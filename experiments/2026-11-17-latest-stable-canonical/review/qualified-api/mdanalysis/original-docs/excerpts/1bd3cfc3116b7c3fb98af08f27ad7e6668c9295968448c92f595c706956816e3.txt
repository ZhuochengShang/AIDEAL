parse_chainids(num_per_record: int, numlines: int)[source]

Extracts the chainID of each residue

Parameters:

num_per_record (int) – The number of entries for each record in section (unused input)

numlines (int) – The number of lines to be parsed in current section

Returns:

attr – A numpy array containing the chainID of each residue as defined in the parm7 file

Return type:

numpy array
