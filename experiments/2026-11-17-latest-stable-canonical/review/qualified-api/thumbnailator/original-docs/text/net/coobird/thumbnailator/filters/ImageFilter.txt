public interface
ImageFilter
This interface is to be implemented by classes which performs an image
filtering operation on a
BufferedImage
.
The general contract for classes implementing
ImageFilter
is that
they should not change the contents of the
BufferedImage
which is
given as the argument for the
apply(BufferedImage)
method.
The filter should make a copy of the given
BufferedImage
, and
perform the filtering operations on the copy, then return the copy.
