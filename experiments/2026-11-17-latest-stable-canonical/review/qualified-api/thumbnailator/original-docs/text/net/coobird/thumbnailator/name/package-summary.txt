net.coobird.thumbnailator.name (Thumbnailator API Documentation (Version 0.4.21))
Package net.coobird.thumbnailator.name
This package contains classes used to generate file names when saving
thumbnail images to files.
See:
Description
Class Summary
ConsecutivelyNumberedFilenames
This class is used to produce file names based on a given format string
and an internal counter which increments every time a new file name
is produced.
Rename
This class is used to rename file names.
