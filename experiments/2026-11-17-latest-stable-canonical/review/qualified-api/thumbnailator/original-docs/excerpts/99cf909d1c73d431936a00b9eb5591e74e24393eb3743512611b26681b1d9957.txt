newRotator
public static
Rotation.Rotator
newRotator
(double angle)
Creates a new instance of
Rotator
which rotates an image at
the specified angle.
When the
Rotation.Rotator
returned by this method is applied, the image
will be rotated clockwise by the specified angle.
Parameters:
angle
- The angle at which the instance of
Rotator
is to rotate a image it acts upon.
Returns:
An instance of
Rotator
which will rotate
a given image.
