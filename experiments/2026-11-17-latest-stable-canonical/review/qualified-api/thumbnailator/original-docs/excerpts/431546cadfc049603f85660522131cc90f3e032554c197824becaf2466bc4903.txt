FixedSizeThumbnailMaker
public
FixedSizeThumbnailMaker
(int width,
int height,
boolean aspectRatio)
Creates a
FixedSizeThumbnailMaker
which creates thumbnails
with the specified size. Whether or not the aspect ratio of the original
image should be preserved by the thumbnail is also specified at
instantiation.
Parameters:
width
- The width of the thumbnail to produce.
height
- The height of the thumbnails to produce.
aspectRatio
- Whether or not to maintain the aspect ratio in the
thumbnail the same as the original image.
If
true
is specified, then the
thumbnail image will have the same aspect ratio
as the original image.
