ConsecutivelyNumberedFilenames
public
ConsecutivelyNumberedFilenames
(
File
dir)
throws
IOException
Instantiates an
ConsecutivelyNumberedFilenames
object which
returns
File
s with file names which are consecutively numbered
beginning from
0
, with the directory specified.
File name sequence
For a case where the parent directory is
/foo/bar/
:
/foo/bar/0
/foo/bar/1
/foo/bar/2
/foo/bar/3
and so on.
Parameters:
dir
- The directory in which the files are to be located.
Throws:
IOException
- If the specified directory path is not a directory,
or if does not exist.
