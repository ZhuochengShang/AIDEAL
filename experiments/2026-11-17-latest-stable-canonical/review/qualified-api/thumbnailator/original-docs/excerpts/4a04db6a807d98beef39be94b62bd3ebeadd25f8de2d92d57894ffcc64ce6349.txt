Crops the enclosed image if the enclosing image is smaller.
Parameters:
width
- The width of the filtered image.
height
- The height of the filtered image.
position
- The position to place the enclosed image.
fillColor
- The color to fill portions of the image which is
not covered by the enclosed image. Portions of the
image which is transparent will be filled with
the specified color as well.
