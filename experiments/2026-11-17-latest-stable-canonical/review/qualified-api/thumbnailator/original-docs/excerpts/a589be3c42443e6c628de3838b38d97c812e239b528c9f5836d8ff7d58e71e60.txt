getOutputQuality
public float
getOutputQuality
()
Returns the compression quality settings for the thumbnail.
The value is in the range of
0.0f
to
1.0f
,
where
0.0f
is for the lowest quality setting and
1.0f
for
the highest quality setting.
If the default compression quality is to be used, then this method will
return
DEFAULT_QUALITY
.
Returns:
The compression quality settings for the thumbnail.
