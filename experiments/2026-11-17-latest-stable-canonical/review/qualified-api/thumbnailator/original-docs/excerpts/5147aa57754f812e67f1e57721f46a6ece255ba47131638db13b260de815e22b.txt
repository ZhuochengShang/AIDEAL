isSupportedOutputFormatType
public static boolean
isSupportedOutputFormatType
(
String
format,
String
type)
Returns whether a specified format type is supported for a specified
output format.
Parameters:
format
- The format to check whether it is supported or not.
type
- The format type to check whether it is supported or not.
Returns:
true
if the format type is supported by the
specified supported format,
false
otherwise.
