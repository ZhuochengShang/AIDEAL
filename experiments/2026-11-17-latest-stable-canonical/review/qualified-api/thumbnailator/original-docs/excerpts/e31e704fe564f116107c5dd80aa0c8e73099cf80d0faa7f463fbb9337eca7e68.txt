calculate
Dimension
calculate
(int width,
int height)
Calculates the size of the object.
Parameters:
width
- Width of the object which encloses the object
for which the size should be determined.
height
- Height of the object which encloses the object
for which the size should be determined.
Returns:
Calculated size of the object.
Throws:
IllegalArgumentException
- If the width and/or height is less than
or equal to
0
.
