FixedSizeThumbnailMaker
public
FixedSizeThumbnailMaker
(int width,
int height)
Creates a
FixedSizeThumbnailMaker
which creates thumbnails
with the specified size.
Before this instance is able to produce thumbnails, whether or not the
aspect ratio of the original image should be maintained in the thumbnail
must be specified by calling the
keepAspectRatio(boolean)
method.
Parameters:
width
- The width of the thumbnail to produce.
height
- The height of the thumbnails to produce.
