keepAspectRatio
public
FixedSizeThumbnailMaker
keepAspectRatio
(boolean keep)
Sets whether or not the thumbnail is to maintain the aspect ratio of
the original image.
Parameters:
keep
- Whether or not to maintain the aspect ratio in the
thumbnail the same as the original image.
If
true
is specified, then the
thumbnail image will have the same aspect ratio
as the original image.
Returns:
A reference to this object.
Throws:
IllegalStateException
- If whether to keep the aspect ratio has
already been previously set.
