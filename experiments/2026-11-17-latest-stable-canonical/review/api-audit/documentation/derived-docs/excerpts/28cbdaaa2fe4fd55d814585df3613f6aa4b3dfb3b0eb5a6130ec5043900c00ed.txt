MDAnalysis.lib.util.convert_aa_code(x)[source]

Converts between 3-letter and 1-letter amino acid codes.

Parameters:

x (str) – 1-letter or 3-letter amino acid code

Returns:

3-letter or 1-letter amino acid code

Return type:

str

Raises:

Note
