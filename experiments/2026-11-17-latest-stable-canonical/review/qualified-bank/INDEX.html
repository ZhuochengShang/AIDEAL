What the native microbenchmark measures

The audience writes one program for the selected API using the prepared documentation, scaffold and fixtures. It supplies assertions plus the configured checked witness. Audience-written assertions are not an independent oracle. The actual generated program, delivered prompt, expected values and execution output do not exist until an approved model call and subsequent execution. This browser does not invent them.

R0 is the first program; R1/R2 are later bounded repairs after actual failures. Wrapper/body notes and unknown arity remain visible. Selection does not certify universal semantic uniqueness or removal of every wrapper.
