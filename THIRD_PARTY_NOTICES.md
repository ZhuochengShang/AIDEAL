# Sources and third-party material

The AIDEAL engine was developed from the author's existing GRAIL engine snapshot
at revision `ddda36fe1892a478519e9e359b526b0a856e287b`, with subsequent AIDEAL
development and cleanup. That revision identifies the source snapshot, not the
version of every historical experiment. The Python distribution retains the
compatibility name `grail-agent`; its import and command names are `aideal`.

This publication contains the toolkit, prompts, configuration examples, synthetic
software tests and source-only historical readers/adapters. It does not contain
the attached RDPro or SedonaDB source trees, private task banks, datasets,
compiled harnesses, recorded experiment outputs or the research paper. Source-only
modules under `studies/` require separately supplied artifacts for actual replay.

Historical SedonaDB studies used Apache SedonaDB revision
`59ec34c79594222891b1dbaf106bfa9de14a5b99`. Copied reference pages, fixtures,
upstream LICENSE and NOTICE remain with those external historical artifacts;
they are not included in this toolkit snapshot.

Dependencies are installed separately and retain their respective licenses.
No project-wide open-source license has been selected for this snapshot.
